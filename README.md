# NAVER Ads Conversion Tracking Guide - English

This folder contains an English version of the NAVER Ads conversion tracking documentation.

The site files are inside the `docs` folder and can be published with GitHub Pages.

## Deploy with GitHub Pages

1. Push this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings` > `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select branch `main`.
6. Select folder `/docs`.
7. Click `Save`.

The site will be available at:

```text
https://YOUR_USERNAME.github.io/english_doc/
```

If your repository name is not `english_doc`, update this value in `docs/_config.yml`:

```yaml
baseurl: "/your-repository-name"
```
